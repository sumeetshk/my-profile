## 📁 File Organization Guidelines

### Adding New Content

**New Blog Articles:**
- Save to: `docs/blog/articles/`
- Naming: `NN-article-title.md` (e.g., `02-kubernetes-best-practices.md`)

**New Resume Versions:**
- Current: `resume/current/resume.html` (overwrite or backup old)
- Archive: `resume/archive/resume-vN.html` (keep old versions)

**Portfolio Updates:**
- Current: `portfolio/current/portfolio.html` (latest version)
- Archive: `portfolio/archive/vN/` (old versions in folders)

**Media & Assets:**
- Store in: `docs/assets/`
- Organize by type: `images/`, `diagrams/`, `downloads/`, etc.
